# 👥 HR Data Analysis

## Project Overview

This project analyzes HR data using Python and Pandas to explore employee information, workforce distribution, departments, job roles, and HR-related trends.

## Objectives

- Explore employee data
- Analyze employees by department
- Analyze job roles and workforce distribution
- Explore employee-related trends
- Perform data cleaning
- Perform exploratory data analysis (EDA)
- Create visualizations to communicate insights

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Kaggle

## Data Analysis

The project includes:

- Data cleaning and preparation
- Exploration of employee information
- Department analysis
- Job role analysis
- Workforce distribution analysis
- Exploration of HR-related trends
- Exploratory data analysis

## Data Visualization

Created visualizations using Matplotlib to present employee distribution, departments, job roles, and HR-related trends.
